# Android 28 — установка APK через QR и применение языка

Патч применяется поверх Android 27. Он не содержит игровых APK, OBB или ресурсов
ПК-версии. Нужна новая сборка APK: обновления только JS недостаточно, поскольку
изменены Android Activity и сканер.

## Применить исходники и получить EXE

Сохрани tesl-reborn-android-28.patch в E:\TESL-build. В Ubuntu/WSL:

```bash
cd ~/tesl-reborn-android-review
git status --short
git am /mnt/e/TESL-build/tesl-reborn-android-28.patch && git push
```

`git status` до применения должен показывать чистое рабочее дерево. Ветка —
android-ui-and-update-loader. После push открой GitHub Actions → Build Windows
Builder → последний успешный запуск → Artifacts → TESL-Reborn-Builder-Windows.
Распакуй архив. В self-test.json ожидается core=android-28-install-and-language.

Новый EXE не исправляет APK из прошлых папок результатов автоматически.
Запусти новую сборку с прежней ПК-игрой и оригинальным XAPK. Для проверки выбери
английский и русский. Small APK + data ZIP теперь расположен первым и выбран
по умолчанию. Результат — tesl-reborn.apk и tesl-reborn-data.zip; resources/
сохрани для передачи с ПК. Исходные файлы игры не изменяются.

## Установить APK с ПК без кабеля

1. В новом Builder после сборки нажми Start transfer.
2. На телефоне открой обычную камеру и считай QR с ПК. Откроется страница
   временного сервера Builder. Для первого обновления с Android 27 используй
   именно обычную камеру: старый встроенный сканер принимает только прежний
   формат QR, а Android 28 принимает оба.
3. Нажми Download APK и установи скачанный файл как обновление. Android может
   попросить разрешить установку из браузера и подтвердить обновление.
   Старое приложение и его данные удалять не нужно.
4. Вернись в браузер на ту же страницу. Нажми Open TESL Reborn to download game
   data. Адрес и временный код будут переданы приложению.
5. Выбери игровой язык и нажми Download missing game data, если нужны ресурсы.
   При готовых данных повторно скачивать весь ZIP или OBB не требуется.
6. После проверки установленных данных телефон подтверждает завершение. Через
   60 секунд сервер автоматически прекращает передачу. Скачивание одного APK
   не завершает сервер. Без активности сервер выключается через 15 минут.

Один и тот же QR работает и во встроенном сканере Android 28: Settings → Game
data → Scan QR code to download game data from your PC. В этом случае браузер
не открывается. После сканирования появляется отдельная подсказка: QR code
scanned. Choose your language, then tap Download missing game data.
Считывание QR само по себе не означает успешного соединения с ПК.

Для одного Wi-Fi выбери частный адрес ПК в Advanced connection. Между разными
сетями можно использовать Tailscale на обоих устройствах. Эти варианты не
требуют собственного сертификата. Публичный интернет через обычный внешний IP
не настраивается автоматически; прежний вариант с готовым HTTPS остаётся
в расширенных настройках.

APK передаётся и для режима Offline XAPK: сервер читает APK прямо из готового
XAPK, без распаковки всего комплекта на диск. Страница сервера не загружает
внешние скрипты, шрифты или аналитику. Доступ ограничен временным адресом;
игровые ресурсы по-прежнему требуют код подключения.

## Проверки на телефоне

### Обычный запуск и Game data

- Если OBB, общие ресурсы и выбранный язык уже установлены, запуск значком
  приложения должен сразу открывать игру. Проверка выполняется невидимой
  Activity с Theme.NoDisplay, экран установщика не создаётся.
- Если данные отсутствуют или ещё не подтверждены установщиком, открывается
  подготовка данных. Проверка при обычном старте не перечитывает несколько ГБ
  хешей; используются отметки установки и наличие/размеры файлов.
- Settings → Game data должен по-прежнему открываться явно. Просмотр и возврат
  назад не должны останавливать игру или разрывать вход.
- Новая подпись кнопки системного языка: Use system language for the game.

### Язык внутри игровых Settings

Проверять нужно именно из игровых Settings, а не только выбор в Game data.

1. Войди в игру на английском и выбери русский в игровых Settings.
2. Если русский пакет установлен, выбор применяется через чистый запуск игры,
   без ручного нажатия Launch game в установщике. Ожидается автовход с ранее
   сохранёнными данными, а не повторный ввод пароля.
3. Проверь основное меню, коллекцию/названия карт и настройки. Недостаточно,
   чтобы изменилось только окно Settings. Затем проверь обратный переход.
4. Если пакет отсутствует, должен открыться экран с выбранным нужным языком
   и возможностью установить его из ZIP или скачать с ПК.

Изменения: учитываются асинхронные вызовы после закрытия UI callback и запись
языковой настройки PlayerPrefs. При изменении выбранного кода восстановленный
словарь обновляется даже до изменения CurrentLanguageCode в Unity. Фоновые
вызовы локали вне Settings не считаются выбором пользователя.

С настоящими ресурсами и игровым сервером эти изменения нужно подтвердить
на телефоне: локально доступны только синтетические наборы и проверки логики.

### Камера и QR

Первый запуск после запроса разрешения камеры не должен выдавать
CaptureRequest contains unconfigured Input/Output Surface.

Камера теперь использует TextureView. Размер буфера задаётся до создания Surface;
сессия и CaptureRequest сохраняют одни и те же Surface. Разрешение и жизненный
цикл камеры обрабатываются на главном потоке. Изменение размеров превью меняет
только матрицу изображения. Картинка заполняет область с обрезкой краёв и
равномерным масштабом, вместо узкого вписывания или растягивания.

Проверь первое разрешение камеры, повторное открытие сканера, уход в фон и
возврат, чтение нового QR с ПК. Не очищай данные игры только ради повторного
запроса разрешения: его можно отозвать в настройках Android.

### Скрытый дебаг

Три коротких тапа в самом верхнем левом углу игровой области примерно за одну
секунду. Не по строке состояния Android. Повторный жест должен скрывать меню.
Проверь главное меню и бой. Уведомлений и видимой кнопки нет; серверные права
не изменяются.

Поддержаны строковые и KeyCode-перегрузки, anyKey/anyKeyDown и внутренние функции
ввода Unity, которые могут вызываться в обход публичных IL2CPP-обёрток.
Нажатие D фиксируется на одном кадре фактического запроса, чтобы порядок Update
разных компонентов не терял жест. Ошибка отдельного перехватчика не отключает
остальное распознавание.

Показ настоящего игрового дебаг-меню локально не проверен. Если реакции снова
нет, появился диагностический файл без всплывающих сообщений. При необходимости
в PowerShell с adb на PATH:

```powershell
adb shell cat /sdcard/Android/data/com.bethsoft.theelderscrollslegends/files/tesl-reborn-debug-status.json
```

- ready — перехватчики установлены, жест ещё не распознан;
- gesture-detected — три тапа распознаны, игровой обработчик ещё не запросил D;
- ctrl-d-forwarded — игровой ввод получил Ctrl+D; если меню не появилось,
  нужно смотреть штатный обработчик/доступность меню;
- input-error — ошибка чтения мобильного ввода, подробность в detail.

## Выполненная локальная проверка

- JS-тесты обновлений, входа, UI чата, статистики, языка, эмодзи и дебаг-жеста.
- Python-тесты сборки пакетов, ZIP, сервера, браузерной установки APK, Range,
  доступа по коду и подтверждения установки ресурсов.
- Компиляция Android Java → DEX настоящими SDK/JDK.
- JVM: установка/докачка и проверка хешей, ZIP-импорт, отбрасывание повреждённых
  архивов, разбор старого/нового QR и математика превью при четырёх поворотах.
- Полная сборка и подпись синтетических APK+ZIP и XAPK, проверка манифеста,
  невидимого launcher и передачи подписанного APK с ПК из обоих форматов.

Windows EXE собирается и проверяется workflow. Настоящая камера Pixel, игровые
языковые ассеты и показ серверного дебаг-меню требуют проверки на устройстве.
