# OTA 56: оформление поиска, положение друзей и загрузочная подпись

Требуется 55. После apply.sh выполнить git push в android-ui-and-update-loader, полностью закрыть игру и запустить через значок. APK/OBB/языки пересобирать не нужно.

Магазин и Settings не меняются: отчёт 11 подтвердил успешные store-loaded, пользователь подтвердил отображение изображений.

## Поиск

Высота поля уменьшена 88 -> 68, место над списком 106 -> 82. Сохранены ширина и размер читаемого текста. TextViewport — отдельный родитель Text/Placeholder, а не сам двигающийся Text. Включён режим одной строки, отключён перенос текста, выравнивание слева по вертикальному центру. Это исправляет найденную ошибку построения TMP_InputField, из-за которой введённый текст уезжал вверх.

Из DLL Reborn взяты игровые пути рамки и очистки:
- AppBase/UI/Sprites/Core/UtilityAssets/input-frame
- AppBase/UI/Sprites/Core/UtilityAssets/close-x-icon

Загрузка асинхронная через AssetCatalog, как для магазина. До получения Sprite остаётся прежний фон/X; после успешной загрузки рамка становится sliced, текстовая X заменяется игровой иконкой. Для маски текста используется RectMask2D при доступности API.

## Друзья

При временном переносе оригинальной кнопки в её прежнем месте создаётся невидимый LayoutElement. Он сохраняет ширину/высоту и индекс кнопки в раскладке, поэтому остальные иконки не сдвигаются. Поднятая над модальным окном кнопка следует за экранной позицией этого места. После завершения поиска исходная кнопка возвращается с прежними RectTransform/active/interactable; временное место удаляется и ссылки освобождаются, включая ошибки при восстановлении.

Оригинальные click handlers не меняются. Кнопка по-прежнему временно получает другого родителя для работы поверх модального поиска; визуально она должна оставаться в исходном месте. Отдельный код позиции кнопки в бою не добавлен. Если смещение в бою останется, потребуется отчёт/скрин именно в бою после этой правки.

## Версия

Отчёт 11: нужная перегрузка Sprite.Create отсутствует в Android, поэтому отображался запасной прямоугольник. Градиент теперь рисуется 32 неинтерактивными полосами UI.Image без Texture2D/Sprite.Create. Подпись уменьшена до 620×72, основной шрифт 26, поднята выше полосы загрузки: запасная верхняя точка y=.34 вместо .30. Две строки Reborn / Android сохранены. Положение привязывается к логотипу, если доступна его геометрия, и сохраняется всю загрузку.

## Проверки

Проверены: асинхронная загрузка native UI sprite и освобождение ссылок; сохранение места оригинальной кнопки, следование позиции и возврат; видимость/позиция подписи; другие JS-тесты и 30 Python-тестов. Применение патча проверено. Реальная Android-раскладка и исправление положения введённого текста ещё не подтверждены на устройстве.

Проверить: поиск до/после ввода и скрытия клавиатуры; очистку; высоту первого ряда; друзей до/во время/после поиска и в бою; подпись относительно логотипа/прогресс-бара/подсказки. При проблеме прислать скрин и ZIP через Game Data.
