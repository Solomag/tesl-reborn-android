# OTA 32 — состояние языка и правильное окно Settings

Для установленного APK 31 новый APK не нужен. Патч уже содержит подготовленные
updates/test/manifest.json и updates/payloads/<sha256>.js. После git push телефон
с включёнными Automatic patch updates сможет скачать этот JS напрямую с GitHub.
Сборку Builder в Actions ждать не требуется.

## Применение

Сохранить tesl-reborn-android-32-ota.patch в E:\TESL-build. В WSL:

```bash
cd ~/tesl-reborn-android-review
git am /mnt/e/TESL-build/tesl-reborn-android-32-ota.patch && git push
```

Открыть Game Data → Advanced и проверить Automatic patch updates. Если включён
safe mode, он блокирует проверку обновлений. Затем полностью остановить игру
через настройки Android → Force stop и запустить. Проверка проходит примерно
через 10 секунд после инициализации hook; дождаться её, затем открыть Game Data.
При сообщении о скачанном обновлении ещё раз полностью остановить и запустить игру.
Смахивания из недавних может быть недостаточно. ADB и ПК для самой загрузки не нужны.

В статусе загрузчика ожидается current.revision=32,
current.version=android-32-language-state-ota, pending=null после успешного старта.
На GitHub адрес канала должен уже показывать revision 32. Старая ревизия 24
означает, что новый манифест ещё не получен по этому адресу.

## Что показали отчёты

Во всех трёх отчётах выбран en_us, но managerLanguage=ru. Английская таблица
содержит 15645 строк и почти не содержит кириллицы; русская таблица также установлена.
Это подтверждённый рассинхрон выбранного и внутреннего языка, а не отсутствие
английской таблицы. Метаданные показывают LocalizedLanguage в SetLanguage,
GetSystemDefaultLanguage и SettingsManager.GetCurrentLanguage.

Лишняя Game Data находится в OptionsWinMobile(Clone). Нужная — в
SettingsWin_Mobile(Clone), вложенном в PopupWinTemplate. Патч различает эти
конкретные классы/корни, а не наличие произвольного слайдера.

## Изменения и проверка

- LocalizedLanguage берётся из реальных констант/объектов игры. Числовой ID языка
  не приравнивается к порядку PC-пакетов.
- SettingsManager и системный выбор используют тот же выбранный язык. Если
  LocalizationManager уже инициализирован прежним языком, состояние сверяется и
  обновляется с восстановлением таблицы и вызовом UpdateObjects.
- Перехвачен реальный HandleLanguageOnValueChanged. Штатный Dropdown сохраняется;
  выбранный язык передаётся в рабочий путь Game Data до запуска прежней корутины,
  которая могла инициировать выход. При невозможности распознать элемент остаётся
  запасной отдельный Android-список.
- Game Data удаляется из OptionsWinMobile, остаётся в SettingsWin_Mobile.
- Успешно проверенная отметка Ctrl+D выключается однократно через конфиг.
  Жест и права debug не меняются. Если рамка осталась на первом запуске OTA,
  свернуть/развернуть игру: Java перечитает конфиг при onResume. Впоследствии
  отметку можно вручную вернуть переключателем Advanced — OTA не будет её
  снова принудительно выключать.

На телефоне проверить EN → RU → EN: загрузку, обычные Settings, коллекцию и
отсутствие повторного запроса пароля. Это ожидаемое поведение, а не уже
подтверждённый результат: телефона в среде сборки нет.

Тесты воспроизводят подтверждённый рассинхрон en_us/ru, произвольные реальные
enum-ID вместо индексов ресурсов, обновление словаря, штатный callback Dropdown,
корни из отчётов и передачу подготовленного настоящего payload через загрузчик
со старой встроенной версией. Тестовый адаптер не исполняет Unity-код на телефоне.

Если останется рассинхрон, дополнительная диагностика пишет
files/tesl-reborn-language-state.json. В прежний Collect-Settings добавлена
информация о типе LocalizedLanguage. Файлы паролей для этого не нужны.

## Последующие обновления

Для изменений только JS править hook.ts, выполнять npm run build, затем
python3 tools/publish_hook.py с новой свободной ревизией и тем же base-url.
В Git должны попасть не только исходники, но и updates/test/manifest.json
с updates/payloads/<sha256>.js. Именно эти два файла скачивает телефон.

OBB и языковые пакеты этим загрузчиком не скачиваются. Java-часть Game Data,
камера, Android-обработчики, тема Android-экрана и сам загрузчик требуют нового APK.
Полный архив игровых данных при изменениях кода повторно собирать не требуется.
