# OTA 35: штатный пункт «Русский язык»

Скриншот телефона подтвердил точную подпись пункта: «Русский язык».
Прежний хук принимал «Русский» и Russian, поэтому выдавал Unknown language label
и открывал резервный ручной выбор. Добавлена точная подпись из игры.
Другие неизвестные подписи теперь записываются в лог (до 120 символов).

Тест использует настоящий распознаватель текста и настоящую подпись из скриншота,
проверяет прямой переход language=ru_ru&apply=1, сохранение штатного списка,
отсутствие вызова прежнего обработчика выхода из аккаунта и повторного запуска
при выборе уже активного языка. Раньше этот тест подменял распознаватель заглушкой
и поэтому не обнаруживал пропущенную подпись.

## Применение

Сохранить патч в E:\TESL-build. В WSL:

```bash
cd ~/tesl-reborn-android-review
git am /mnt/e/TESL-build/tesl-reborn-android-35-ota.patch && git push
```

Применять один раз. Патч уже содержит manifest и payload для тестового канала.
Сборка EXE/APK не нужна: установленный Android 34 может загрузить OTA 35.
Игровые данные и языковые пакеты повторно передавать не требуется.

После push полностью остановить игру через Android → сведения о приложении →
«Остановить», запустить и оставить открытой с интернетом примерно на 20 секунд.
Снова полностью остановить и запустить: обновление применяется при следующем
старте процесса. Одного смахивания из недавних приложений может быть недостаточно.

Для проверки с ПК в PowerShell:

```powershell
adb shell cat /sdcard/Android/data/com.bethsoft.theelderscrollslegends/files/tesl-reborn-update-status.json
```

Ожидается current.revision=35, current.version=android-35-russian-language-label,
pending=null. Затем проверить EN → «Русский язык» → English из игрового списка.
Промежуточный тёмный экран при перезапуске Unity остаётся; вручную выбирать русский
в Game Data при установленных ресурсах больше не должно требоваться.

## Границы исправления

Этот патч исправляет распознавание пункта языка. В переданном switch.log автовход
получил HTTP 200, русский словарь был восстановлен. Ранее замеченные
ClientHttpErrorUnknown, зависание загрузки и поддержка менеджера паролей Android
этим патчем не исправляются и требуют отдельного разбора при воспроизведении.
Логика перезапуска Java/Activity и авторизации не менялась.
