# OTA 55: магазин и исправления интерфейса

Требует 54. Пересборка APK/OBB/языков не нужна. После apply.sh выполнить git push в android-ui-and-update-loader, полностью закрыть игру и запустить через значок для OTA 55.

## Магазин

Отчёт 10 подтверждает `store image factory failure: Error: expected a pointer` до постановки очереди. В 54 ссылочное поле `$current` очищалось JS null, тогда как используемый bridge вызывает NativePointer.writePointer и требует нулевой NativePointer. В 55 все очистки ссылочных полей секции магазина используют ptr(0). Исправлена и очистка операции при завершении. Тест фабрики теперь моделирует отказ при JS null; прежний тест этого не проверял.

Это исправляет обнаруженный сбой запуска. Получение реальных Sprite на телефоне ещё не подтверждено. После входа в магазин подождать 25 секунд и проверить отчёт на store-queued/request/loaded/missing/error/timeout.

## Поиск колод

Поле увеличено с 420×52 до 760×88 единиц интерфейса, основной текст до 32, подсказка до 30. Кнопка очистки — видимая X, 100×72, шрифт 32 вместо маленького символа ×. Справа зарезервировано место под неё.

Под поле выделяется 106 единиц высоты: изменяется верхний край viewport родительского ScrollRect, а не управляемый layout-системой контент `_grid`. Если ScrollRect API недоступно, запасной вариант — прежний RectTransform. После закрытия отступ возвращается.

## Друзья

Новая кнопка Friends больше не создаётся. Находится исходная `_friendsBtn` в MainMenuOverlayView/MainMenuWin/OverlayMenu, переносится поверх модального поиска с сохранением экранной геометрии, включается interactable. Оригинальные события не меняются. Нативная панель FriendsWin располагается выше модального поиска. После отмены/закрытия восстанавливаются родители, порядок, RectTransform, activeSelf и interactable. Если оригинальный компонент не найден, записывается ошибка, дубликат не создаётся.

## Подпись Reborn

Две строки: `Reborn 1.3.1-beta` и `Android · APK … · patch 55`. Добавлен чёрный градиент от прозрачных краёв к центру по алгоритму SplashWinPatch в предоставленной DLL. При недоступности API генерации Sprite остаётся тёмный фон. Положение под логотипом и продолжительность до готовности меню сохранены.

Версия Reborn — версия перенесённого ПК-плагина, не онлайн-версия сервера. HTTP-заголовок совместимости не изменён.

## Проверка

Unit/runtime mocks: фабрика магазина с отказом на JS null, асинхронная загрузка/таймаут/освобождение ссылок; перемещение оригинальной кнопки друзей, сохранение обработчика, возврат родителя/порядка/interactable; две отдельные строки версии. Остальные JS-тесты и 30 Python-тестов прошли. Применение патча проверено. На реальном Android и с реальными ассетами здесь не запускалось.

На телефоне: проверить размеры/очистку поиска, отсутствие перекрытия первого ряда, оригинальную кнопку друзей при поиске и после отмены, подпись загрузки и магазин. Подтверждённое исправление моргания Settings не менялось.
