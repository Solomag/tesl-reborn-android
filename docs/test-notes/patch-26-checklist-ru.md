# Android 26: исправления после проверки на телефоне

## Обновить сборщик

Применяется только новый патч `tesl-reborn-android-26.patch`, поверх уже
применённого исправления Windows. Сохрани его в `E:\TESL-build`, затем в WSL:

```bash
cd ~/tesl-reborn-android-review
git am /mnt/e/TESL-build/tesl-reborn-android-26.patch
git push
```

В Actions скачай новый artifact TESL-Reborn-Builder-Windows. Старый запуск
повторять не нужно: новый push запустит сборку с изменениями. Изменилась нативная
часть Android, поэтому одного OTA-обновления хука недостаточно: нужен новый APK.
Данные игры и учётную запись удалять не нужно.

## Как теперь пользоваться

1. Укажи ПК-игру и оригинальный XAPK. «Output folder» — только папка результатов;
   по умолчанию `output` рядом с EXE. Временные файлы находятся внутри неё в
   `.work/run-…` и удаляются после сборки. Исходная игра не изменяется.
2. Выбери формат: XAPK для установщика XAPK или APK+OBB. Формат не определяет
   способ передачи: OBB можно скопировать вручную или скачать с ПК.
3. Отдельно выбери, включать ли языки в APK. Если включены, телефон установит
   их из APK. Если нет — скачает выбранный язык и общие ресурсы по QR.
4. Выбери язык игры. По умолчанию подготовлен английский; добавь русский для
   проверки переключения. «Phone system language» использует настройки телефона.
   Язык интерфейса сборщика и экрана подготовки выбирается отдельно; начальный
   интерфейс английский, основные элементы переведены на языки оригинала.
5. Собери комплект и обнови APK поверх установленного. Для ADB в PowerShell:
   `adb install --no-streaming -r "полный-путь-к-новому-APK"`.
6. Для передачи нажми Start transfer. В Android-приложении нажми Scan QR code,
   разреши камеру и считай QR на ПК. Затем нажми Download missing game data and
   language. Ручной ввод адреса/кода оставлен как запасной способ.
7. Wi-Fi: телефон и ПК должны видеть друг друга в одной сети. Tailscale: включи
   его на обоих устройствах; в Advanced connection выбери адрес ПК 100.64–127.x.x.
   В этих двух режимах собственный сертификат не нужен. Публичный HTTPS оставлен
   в дополнительных настройках для уже настроенного сервера; публичные
   нешифрованные HTTP-адреса не принимаются.
8. По сети теперь передаётся и OBB. Если он уже скопирован вручную, приложение
   проверит размер и SHA-256. Статусы OBB, общих данных и языка раздельные.
   Подтверждение ПК отправляется после проверки полного комплекта. После
   возврата в приложение состояние OBB обновляется без ручного перезапуска.
9. Альтернатива: Import OBB file позволяет выбрать OBB из доступной папки,
   например Downloads. Само приложение положит его в свою папку Android/obb.
   Для полного XAPK подходящий установщик также может установить OBB сам.

Open a previous build — открыть папку уже созданного результата, чтобы передать
его ещё раз. Внутренний catalog.json выбирать вручную больше не нужно. ПК нужно
держать включённым до подтверждения готовности телефона. Сервер останавливается
через минуту после этого подтверждения либо через 15 минут простоя.

## Проверить языки и вход

- Сначала английский: меню, названия/тексты карт и бой.
- Потом русский: открыть Resources, выбрать русский, установить/скачать его и
  нажать Launch game. Подготовка живёт в отдельном процессе и закрывает старую
  Unity, поэтому данные не заменяются под работающей игрой.
- При смене языка через прежние игровые настройки хук переводит поддерживаемый
  запрос в экран подготовки. Для проверки предпочтителен Resources.
- Вернуться на английский. Системный язык также проверить отдельно.
- Сохранённые данные входа больше не удаляются при повторном появлении окна
  входа. Автовход выполняется не более одного раза на процесс. Повторное окно
  само по себе не означает неправильный пароль. Причина общего HTTP-сбоя без
  свежего лога по-прежнему не установлена.

Для поддержанных форматов таблиц сборщик дополнительно извлекает строки из
ПК-бандла локализации в проверяемый пакет. Если отдельную таблицу извлечь нельзя,
он сообщает это в build.log и использует оригинальный текстовый бандл Unity.
Совместимость конкретного набора ПК-ассетов подтверждается проверкой на телефоне,
а не синтетическим тестом.

## Скрытый жест для тестера

Тройной тап в верхней левой области с логотипом (три отпускания менее чем за
0,9 секунды) имитирует Ctrl+D внутри исходного обработчика debug-меню. Видимой
кнопки, уведомления или переключателя прав нет. Серверная проверка доступа
остаётся штатной. На телефоне это ещё нужно подтвердить: если обработчик в этой
сборке называется иначе, в логе будет `original debug input poller not found`.
Обычные нажатия клавиатуры вне этого обработчика не меняются.

## Проверки до передачи

- JS и Python: тесты старого интерфейса/OTA и новые проверки языкового старта,
  повторного окна входа, скрытого сочетания и подтверждения установки OBB.
- Реальный JVM: сетевой OBB, докачка, SHA-256, восстановление повреждённого кеша,
  Tailscale-адреса, отклонение публичного HTTP и декодирование QR через ZXing.
- Android Activity и сканер компилируются; полный синтетический прогон проверяет
  подпись APK, DEX/манифест, APK+OBB и XAPK.

На устройстве ещё нужны камера, реальные ассеты, язык и серверный debug-доступ.
Если снова появятся ключи вместо текстов или HTTP-ошибка, сохрани свежий лог
после воспроизведения. Не публикуй пароль, tesl-login.json или код передачи.
