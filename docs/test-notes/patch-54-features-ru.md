# OTA 54: магазин, поиск колод, друзья и версия загрузки

Требует патч 53. APK, OBB и языки пересобирать не нужно. После применения и git push в android-ui-and-update-loader полностью закрыть игру и запустить через значок для получения OTA 54.

## Магазин

Отчёт 9: работает 53, секция магазина установлена, но нет даже store-request. В 54 очередь создаётся в onLeave фабрики StoreImageUtils.LoadStoreImageCoroutine, без зависимости от Unity-вызова IEnumerator.MoveNext. Для готовых AppBase/UI/Textures/Store/img_-?число_2 исходный IEnumerator возвращается завершённым; отдельная задача удерживает его GC handle и доставляет callback после AssetCatalog Sprite/png. Удалён перехват Dispose: завершение пустого IEnumerator не должно отменять независимую загрузку.

Загрузка по-прежнему выполняется вне нативного перехвата, лимит 64 задач, ожидание до 20 секунд. Логи: store-queued -> store-request -> store-loaded/store-missing/store-error/store-timeout. Отсутствие реальных ресурсов этот патч само по себе не исправляет. Причина потери запуска в 53 по отчёту окончательно не доказана; новая схема устраняет зависимость от прежней точки запуска.

## Поиск колод

Поле Search decks / Поиск колод в DeckPickerWin. Фильтр по подстроке без учёта регистра, поддерживает кириллицу и Unicode; × очищает запрос. Скрываются только изначально активные DeckTile, шаблоны не включаются. Данные колод и выбор колоды явно не меняются. При закрытии окна фильтр снимается, панель поиска удаляется и отступ списка восстанавливается.

## Друзья при поиске матча

В MatchSeekingWin добавлена кнопка Friends / Друзья снизу слева. Она открывает исходный FriendsWin над поиском; сохраняется геометрия панели и оригинальные обработчики. При закрытии, отмене поиска или уничтожении окна восстанавливаются родитель и порядок панели. ПК-пути MainMenuOverlay_Desktop и FriendsWinDesktop не используются.

## Версии

Подпись: Reborn 1.3.1 · APK <сборка> · patch 54. Reborn 1.3.1 — версия предоставленного ПК-плагина, поведение которого переносится, а не проверенная версия удалённого сервера. Beta в HTTP-заголовке совместимости сохранено. Положение подписи вычисляется под _logoImage исходного SplashWin; оно запоминается после скрытия SplashWin и сохраняется до готовности главного меню. Если нужные API недоступны, остаётся прежнее запасное положение.

1. Дождаться версии patch 54.
2. Магазин: открыть пустые товары на 20–25 секунд. Если картинок нет, отправить ZIP из Game Data: нужны новые store-queued/request/loaded/error.
3. Выбор колод: поиск латиницей/кириллицей, очистка ×, закрытие и повторное открытие, выбор найденной колоды.
