# Android 30 — выбор языка через рабочий механизм Game Data

Патч поверх Android 29 и исправления шрифта Builder. Для него нужна новая сборка
APK: добавлен отдельный список выбора языка в Android Activity. Данные приложения,
OBB и установленные языковые пакеты сохраняются при установке поверх.

## Применение

Сохранить tesl-reborn-android-30.patch в E:\TESL-build. В Ubuntu / WSL:

```bash
cd ~/tesl-reborn-android-review
git am /mnt/e/TESL-build/tesl-reborn-android-30.patch && git push
```

Дождаться GitHub Actions → Build Desktop Builders. Скачать новый Windows EXE
или Linux-артефакт. Собрать APK с прежними исходной ПК-игрой и оригинальным XAPK.
Установить поверх существующего приложения. Удалять приложение или его данные
не требуется. Для проверки достаточно EN и RU, если они уже установлены на телефоне.

Не использовать для проверки старый APK из output предыдущей сборки.
В Game Data заголовок должен показывать Android 30. В статусе загрузчика текущая
версия — android-30-language-control-routing. Публикация тестового OTA не выполнялась;
новый встроенный core имеет ревизию 30 и не заменяется старым feed с ревизией 24.

## Ожидаемое поведение

- Нажатие выбора языка во внутриигровых Settings открывает наш Android-список
  языков. Для распознанных языковых Dropdown, кнопок и Settings callbacks штатный
  обработчик смены подавляется до вызова его слушателей.
- Выбранный установленный язык проверяется и применяется тем же launchGame →
  startGame путём, что и в Game Data. Это чистый перезапуск игрового процесса,
  а не частичная смена словаря поверх работающей игры.
- Если нужного языка нет, остаётся Game Data с выбранным языком и сообщением,
  что пакет нужно скачать. Устанавливать отсутствующий язык молча нельзя.
- Cancel возвращает в игру без применения; повторный вход в выбор работает.
- В Game Data: Game language at launch / Язык игры при запуске — выбор одного
  активного языка. Choose language packs and download / Выбрать и скачать
  языковые пакеты — получение нескольких пакетов или всех сразу. Эти операции
  независимы: скачанные языки не становятся одновременно активными.
- Кнопка Game Data добавляется только в распознанное окно с языковыми элементами.
  Один слайдер звука или переключатель в меню шестерёнки больше не достаточен.

## Короткая проверка на телефоне

1. Открыть меню шестерёнки до Settings: лишней Game Data там быть не должно.
   Внутри настоящих Settings кнопка должна остаться.
2. Внутри Settings нажать выбор языка. Должен открыться наш Android-список.
   Сначала нажать Cancel, затем повторить и выбрать русский.
3. После запуска проверить не только настройки, но и карты, коллекцию и подписи
   в основном меню. Повторить русский → английский. Отдельно отметить, просит ли
   снова пароль: рабочий путь Game Data используется тот же, но поведение
   авторизации на реальном сервере локальными тестами не подтверждено.
4. В Game Data проверить новые подписи и выбор нескольких пакетов после
   нажатия Выбрать и скачать языковые пакеты.

Если вместо Android-списка по-прежнему открывается старый выбор/немедленно меняются
только настройки, перехват конкретного игрового элемента не сработал. Не считать
это успешной проверкой. Для диагностики в PowerShell:

```powershell
adb shell cat /sdcard/Android/data/com.bethsoft.theelderscrollslegends/files/tesl-reborn-language-status.json
adb logcat -d -s tesl-hook > E:\TESL-build\android-30-language.log
```

Файл language-status записывается при запросе перехода в Game Data; это отметка
вызова перехода, а не доказательство успешного применения языка. Статус предыдущей
попытки может остаться, поэтому важны его revision и время at.

## Проверки и границы

Автоматические проверки: подмена языкового control до штатного обработчика;
работа без распознанного Settings root; повторный вход после Cancel; сохранение
обычных графических Dropdown, Play и программной инициализации; отсеивание
меню с обычными контролами; сборка Android Java в DEX. Полный npm test включает
JS-проверки, проверки загрузчика/хешей и 22 Python-теста. JVM-проверки установщика
прошли. Полная синтетическая сборка APK+ZIP и XAPK с реальной подписью прошла;
это не оригинальная игра и не проверка игрового интерфейса.

Без телефона и игровых метаданных здесь нельзя подтвердить, какой именно
мобильный prefab использует эта версия клиента, и воспроизвести авторизацию
с реальным сервером. Тестовые UI-объекты не заменяют проверку на Pixel.

Медленная/обрывающаяся загрузка APK через браузер в этом патче не изменялась.
Причина пока не установлена; провайдер не признан причиной без проверки.
