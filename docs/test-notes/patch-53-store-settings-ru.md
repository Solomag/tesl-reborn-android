# OTA 53: повторная правка магазина и Settings

Отчёт 8 подтверждает запуск 52, но исправления не сработали. Для магазина видны store-request без store-loaded, store-error или store-missing. Settings вызывает SetResolution с текущими размерами и fullscreen=false.

## Изменения

- Settings: при работе с окном настроек подавляется запрос текущих размеров с частотой по умолчанию независимо от desktop-параметра fullscreen. Ранее несовпадение fullscreen мешало пропуску. Вне Settings, при новых размерах или явной частоте исходный метод сохраняется.
- Магазин: запрос AssetCatalog, IsDone/GetAsset и callback вынесены из нативного MoveNext в существующий планировщик Unity main thread. Это позволяет вложенным Android-перехватам ресурсов выполниться, а не подавляться вложенным Frida-вызовом.
- Managed-корутина удерживается GC handle до завершения/Dispose/ошибки/таймаута; Current пустой, ожидание идёт по кадрам. Операция хранится в managed-поле. Таймаут 20 секунд оставляет store-timeout, а не бесконечную тишину. Обычные URL передаются исходному MoveNext.

Магазин: причина зависания по отчёту не доказана окончательно. Это исправление обнаруженного недостатка реализации, требующее проверки на телефоне, а не подтверждение восстановления картинок.

## Проверка

Требуется патч 52. Применить apply.sh, git push в android-ui-and-update-loader. Полностью закрыть игру и запустить через значок, дождаться OTA 53. APK/OBB/языки пересобирать не нужно.

Проверить Settings -> Cancel; затем проблемный раздел магазина, подождать 20–25 секунд. При проблеме отправить ZIP диагностики. Ожидается SetResolution-skipped при Cancel и store-loaded при успешных изображениях. store-missing означает отсутствие Sprite/операции; store-timeout означает незавершённую операцию.

Тесты включают фактический runtime-адаптер корутины с проверкой отсутствия загрузки/callback внутри нативного перехвата, ожидание, Dispose до старта, таймаут, освобождение GC handle, отсутствие ассета и оригинальную ветку URL. На телефоне здесь не проверено.

Поиск колод, друзья во время поиска матча и размещение версии по образцу SplashWin в этот исправляющий выпуск не входят и остаются следующими задачами.
