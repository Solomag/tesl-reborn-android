# Android 27 — ZIP-установщик и исправления после PR #1

## Обновить исходники

Этот патч применяется поверх Android 26. Сохрани `tesl-reborn-android-27.patch`
в `E:\TESL-build`, затем в Ubuntu WSL:

```bash
cd ~/tesl-reborn-android-review
git am /mnt/e/TESL-build/tesl-reborn-android-27.patch
git push
```

В Actions дождись новой успешной сборки Build Windows Builder и скачай artifact
TESL-Reborn-Builder-Windows. В нём новый EXE. Изменилась Android-часть, поэтому
пересобери и обнови APK поверх текущего. Не удаляй игру и её данные.

## Основной сценарий: компактный APK и один ZIP

1. Укажи ПК-игру, исходный XAPK и папку результатов.
2. Выбери Small APK + data ZIP и нужные языки, для проверки — английский и русский.
3. После сборки для переноса нужны `tesl-reborn.apk` и `tesl-reborn-data.zip`.
   Папка resources — внутренний кеш для сетевой передачи, переносить её не нужно.
4. Установи APK, ZIP положи в Downloads телефона. В экране подготовки нажми
   Import data ZIP и выбери именно этот ZIP. Он содержит OBB, общие данные
   и все языки, отмеченные на ПК. Раскладывать файлы вручную не требуется.
5. Установщик проверяет файлы и размещает их на нужных местах. Временной второй
   копии всего ZIP не создаётся: он читается потоком; отдельный языковой пакет
   временно записывается для проверки и установки. Нужны место под исходный ZIP,
   установленную игру и временный пакет. После успешной установки ZIP можно
   удалить самостоятельно.
6. Выбери язык и нажми Launch game.

Дополнительные языковые пакеты не встраиваются в APK в этом режиме. Исходная
базовая часть APK с кодом/движком и штатными встроенными файлами сохраняется.

Сжатие — ZIP/Deflate уровня 6. Языковые пакеты тоже сжаты для сетевой передачи,
внешний ZIP не сжимает эти архивы повторно. Степень уменьшения зависит от
исходных файлов и записывается в build.log; обещанного процента сжатия нет.
Исходный OBB хранится внутри ZIP с неизменным содержимым, а не модифицируется.

Offline XAPK оставлен альтернативой: APK со встроенными языковыми пакетами и
OBB внутри XAPK для соответствующего установщика.

## Сеть и дополнительные языки

Ручной адрес и код, импорт отдельного OBB и служебные действия находятся
в Advanced. Основные действия — Import data ZIP или Scan QR code.

На ПК нажми Start transfer; на телефоне Scan QR code и Download missing game
data and language. Wi-Fi и Tailscale не требуют собственного сертификата.
По сети скачиваются OBB, общие ресурсы и выбранный на телефоне язык, если они
нужны. Это позволяет не загружать все подготовленные языки сразу. Позднее
можно снова включить передачу и скачать другой подготовленный язык.

Для импорта ZIP устанавливаются все включённые в него языки. Для сетевого
скачивания — выбранный язык. Это два способа получить один и тот же набор
игровых ресурсов, с разным выбором объёма передачи.

## Settings и перезапуски

Кнопка Game data перенесена в окно Settings/Options. Кнопки в чате больше нет.
Она добавляется в игровое окно обычным UI-компонентом; переделка всего Android-
установщика под художественное оформление игры в эту версию не входит.

Простой просмотр данных и возврат назад не должен останавливать Unity или
разрывать игровую сессию. При замене данных или применении другого языка
Unity перезапускается. Скачивание до фактической установки файлов может идти
без остановки старого процесса; применяется остановка перед заменой данных.

## Вход

- HTTP 200 сам по себе больше не считается успешной аутентификацией.
- Пароль сохраняется только после успешного ответа с токеном.
- Подтверждённые коды отказа 15/17 удаляют пароль, сохраняя имя пользователя.
  Сеть, HTTP 5xx, неизвестный ответ или непонятный код не удаляют прежние данные.
- Сохранение выполняется через временный файл и атомарное переименование.
- Отложенный callback нормализует сырой указатель/управляемую обёртку и удерживает
  delegate до вызова. При ошибке вызова показывается штатный вход.
- После явного отказа или повторного экрана входа предпринимается заполнение
  пустого поля имени пользователя. Пароль в поля интерфейса не подставляется.

Нужна одна проверка на телефоне: успешный ручной вход → полный перезапуск →
автовход; затем смена языка → автовход. Существующий нерабочий сохранённый пароль
не считается исправленным автоматически: при необходимости введи его один раз.
Если имя в штатном окне по-прежнему пустое, нужен лог и имя фактического поля
интерфейса; на устройстве эта привязка ещё не подтверждена.

## Камера и скрытый дебаг-жест

Превью камеры сохраняет пропорции с учётом поворота сенсора/экрана; допускаются
чёрные поля вместо растягивания изображения. Выбирается размер, поддерживаемый
и YUV-потоком декодера, и поверхностью превью.

Жест: три коротких тапа в самом верхнем левом углу игровой области менее чем
за 0,9 секунды. Зона небольшая и невидимая, не привязана к логотипу или окну.
Свайпы, долгие нажатия и мультитач не засчитываются. Жест опрашивается глобальным
обновлением ServicesManager, затем штатное Ctrl+D подаётся на один кадр.
Повторный жест должен скрывать меню через тот же исходный обработчик.
Серверные права не меняются, уведомлений нет. Проверить и в меню, и в бою.

## Что перенесено из PR

Исправления адаптированы из PR #1 Frederlk; атрибуция есть в README. Взяты
проверки результата входа, исправления маскирования логов, восстановления после
прерванного копирования, контроля исходников/DEX и ошибок чтения. Исправление
маскирования дополнено для обрезанной строки и незавершённого escape.
Таблица языков PR не копировалась: наш es_mx=3, ru_ru=8, tr_tr=9 сохранён.
Существующие чат, статистика, титулы, подсказки матчей и OTA не заменялись его
собранным hook.js или зависимостями.

## Проверки перед передачей

- Тесты JS: вход/ошибки/сохранение имени, raw/managed callback, секреты в логах,
  глобальный жест, Settings и прежние функции UI/OTA.
- JVM: потоковый ZIP-импорт, сжатые пакеты, SHA-256, отказ от неполных/опасных
  архивов, докачка, удаление языка, QR и математика пропорций камеры.
- Синтетическая сборка: компактный подписанный APK, ZIP данных, автономный XAPK,
  DEX/манифест и сохранность исходной ПК-игры.

Финальный EXE проверяет Windows Actions. Реальная камера, расположение Game data,
автовход, настоящие языковые ассеты и дебаг-меню требуют проверки на телефоне.
Если что-то не работает, сохрани лог после воспроизведения:

```powershell
adb logcat -d -s tesl-hook:I AndroidRuntime:E > E:\TESL-build\android27.log
```

Не присылай tesl-login.json, пароль или код подключения к серверу.
