# TESL Reborn Builder — тестовая версия Android 28

Сборщик работает на Windows без установки WSL, Python или Java. Он использует
ПК-игру и оригинальный Android XAPK только для чтения. Игровые ассеты в git
не размещаются. Получение EXE и проверка обновления описаны в
[android-28-check-ru.md](android-28-check-ru.md).

## Входные данные

- ПК-игра с StreamingAssets. Steam-библиотеки ищутся автоматически; можно
  указать папку вручную.
- Оригинальный single-base XAPK: com.bethsoft.theelderscrollslegends,
  versionCode 11009, с arm64 APK и main OBB.
- Папка результатов. По умолчанию `output` рядом с EXE. Каждая сборка получает
  собственную подпапку build-…; временные файлы `.work/run-…` удаляются после
  завершения. Запись внутрь исходной ПК-игры запрещена, включая случай размещения
  самого EXE в ней.

## Выбрать способ установки

Основной режим — Small APK + data ZIP. Результат для пользователя состоит из
APK и одного ZIP с OBB, общими ресурсами и всеми выбранными на ПК языками.
На телефоне установи APK, затем выбери ZIP через Import data ZIP. Ручная
раскладка кеша и OBB не нужна. Для передачи по сети нажми Start transfer на ПК
и отсканируй QR на телефоне: можно скачать APK, затем недостающие данные и выбранный язык.

Offline XAPK — альтернативный комплект для установщика XAPK: OBB и APK со
встроенными языковыми пакетами. Выбранные языки в основном режиме находятся
в ZIP данных, а не в APK.

Языки интерфейса и игры выбираются отдельно. Начальный интерфейс английский.
Поддерживаются en_us, de_de, es_es, es_mx, fr_fr, it_it, pl_pl, pt_br, ru_ru,
tr_tr; у турецкого исходный инвентарь содержит только текстовый бандл.
Подробный порядок установки и проверки — в android-28-check-ru.md.

## Передача с ПК

После сборки нажми Start transfer. Один QR подходит для двух вариантов:

- Если APK ещё не установлен, сканируй QR обычной камерой телефона. Откроется
  страница ПК с Download APK. Установи скачанный APK, вернись в браузер на эту
  страницу и нажми Open TESL Reborn to download game data.
- Если приложение уже установлено, открой Settings → Game data и сканируй тот
  же QR встроенным сканером. Он сразу заполнит подключение, без страницы браузера.

Выбери язык и нажми Download missing game data. Кадры камеры обрабатываются
локально и не сохраняются. APK можно передать и из Offline XAPK: сервер читает
его прямо из XAPK, без временной распаковки всего комплекта.
Вручную вводить IP и код обычно не требуется; поля оставлены на случай проблем
с камерой. При отказе в разрешении камеры можно использовать внешнюю камеру
или ввести адрес и код.

Для Wi-Fi используется частный адрес ПК, например 192.168.1.x. Для передачи
между разными сетями включи Tailscale на обоих устройствах и выбери его адрес ПК
100.64.0.0–100.127.255.255 в Advanced connection. Собственный сертификат для
этих режимов не нужен. Не выключай ПК до окончания загрузки.

Публичный HTTPS-сервер можно настроить в Advanced connection, но это
дополнительный режим для уже существующей инфраструктуры. EXE не создаёт
туннель, не открывает порты на роутере и не выпускает сертификаты. Публичные
HTTP-адреса и DNS-имена с HTTP не принимаются.

Open a previous build позволяет выбрать папку предыдущего результата и снова
передать его без пересборки. Новая сборка содержит `resources/catalog.json`,
пакеты и `resources/game.obb`. Сервер отдаёт только эти перечисленные файлы,
защищает доступ случайным временным кодом, поддерживает докачку. Стоп — через
60 секунд после подтверждения полного комплекта с телефона или 15 минут
бездействия; активную передачу таймер не прерывает. Закрытие EXE завершает сервер.

## На телефоне

Экран подготовки показывает отдельные статусы OBB, общих ресурсов и языка.
Скачанные данные проверяются по SHA-256; перед запуском дополнительно проверяются
файлы кеша. Ручной OBB можно выбрать через Import OBB file или скопировать
в Android/obb/com.bethsoft.theelderscrollslegends. При возвращении в приложение
он проверяется без ручного перезапуска. До готовности всех трёх компонентов
запуск заблокирован.

Для смены языка используй Game data в Settings, выбери другой язык, установи его
и нажми Launch game. Подготовка работает в отдельном процессе; старая Unity
останавливается при замене ресурсов или применении другого языка. Простой
просмотр экрана и возврат назад не требуют перезапуска.
Настройки входа не стираются. Повторный показ окна входа не трактуется как
доказательство неправильного пароля.

Удаление языка удаляет только управляемые этим пакетом файлы, не используемые
другими установленными пакетами. Общие ресурсы удалить через эту кнопку нельзя.

## Сборка EXE из исходников

GitHub Actions Build Windows Builder выполняет рецепт на Windows и проверяет
замороженный EXE. После успешного запуска скачай artifact
TESL-Reborn-Builder-Windows и распакуй в отдельную папку.

Для ручной сборки на Windows нужны Python 3.12, Node 18+ и JDK 17:

```powershell
python -m pip install -r builder/requirements.txt
python -m builder.bootstrap_tools
python tools/prepare_emojis.py
python android-setup/build.py
npm ci
npm run build
npm test
python android-setup/test_native.py
python -m tests.integration_builder_apk
```

Затем создай `vendor/jre` через jlink по рецепту workflow и выполни
`python -m builder.package_windows`. Windows EXE собирается на Windows.

Инструменты берутся с официальных источников и проверяются по закреплённым
хешам. Emoji читаются из установленного подходящего ПК-плагина либо из
закреплённого официального архива Reborn во время пользовательской сборки;
его DLL не исполняется. Java/apktool/signer/zipalign/Frida и setup DEX входят в EXE.

Подпись совместима с прежним debug certificate uber-apk-signer 1.3.0:
`1e08a903aef9c3a721510b64ec764d01d3d094eb954161b62544ea8f187b5953`.
Это тестовый ключ, а не отдельный приватный релизный ключ. При ошибке обновления
сначала проверь подпись/свободное место, не удаляя рабочую игру и данные.

## Пределы этой версии

- Сборщик переносит ресурсы по versions.json из оригинального Android OBB.
  Произвольные будущие ассеты ПК, отсутствующие в этом инвентаре, не добавляются
  автоматически. Автоматического преобразования будущих DLL нет.
- Для распознанных таблиц локализации извлекается отдельный проверяемый JSON;
  остальные случаи используют текстовый бандл Unity и отмечаются в build.log.
- Обновление JS-хука сохранено. Автоматическая установка новых APK не реализована.
- Камера, реальные игровые ассеты и debug-жест требуют проверки на устройстве.
- Ошибки общего игрового HTTP-соединения требуют свежего лога; этот сборщик
  не меняет серверные права пользователя и не отключает проверку TLS.
