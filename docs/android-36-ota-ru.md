# OTA 36: уведомления об обновлениях

Небольшая тёмная плашка сверху сообщает:

- «Скачивается обновление Reborn. Можно продолжать играть» — после проверки
  манифеста, когда начинается запрос файла патча.
- «Обновление Reborn скачано и проверено. Перезапустите игру, когда будет удобно,
  чтобы применить его» — только после проверки SHA-256/размера и сохранения патча.
- «Обновление Reborn 36 применено» — при следующем запуске, один раз на ревизию.
- При ошибке скачивания/проверки файла — короткое сообщение, что игра продолжает
  работать и следующая попытка будет при новом запуске.

Скачивание/применение показываются на 6 секунд, предложение перезапуска — на 10.
Если файл успел скачаться до появления интерфейса, показывается сразу итоговое
состояние. Сообщение не называет обновление применённым, пока работает старый код.
Перезапуск не навязывается; кнопок, диалогов, паузы и перехвата касаний нет.

Проверка запланирована через секунду после установки хуков, через ранний цикл
ServicesManager.Update, без токена аккаунта. Она не ждёт успешной авторизации,
но сама авторизация тоже не ждёт обновления. Плашка появляется, когда Unity уже
может отрисовать текст. Поэтому показ до завершения быстрого автовхода не
гарантирован. Это уведомление внутри игры, не системное push-уведомление Android.

Простая проверка без новой версии и отсутствие сети на этапе проверки манифеста
не создают всплывающих сообщений. На следующих запусках «применено» не повторяется.
Текущую версию можно посмотреть в Game Data → Advanced.

Сообщения следуют выбранному языку игры: EN, RU, DE, ES/ES-MX, FR, IT, PL, PT-BR, TR.
Плашка имеет собственный Canvas, переживает смену сцен и автоматически исчезает.
При раннем отсутствии шрифта показ откладывается, загрузка игры продолжается.

## Публикация и установка

Этот патч применяется после OTA 35. Сохранить его в E:\TESL-build и в WSL выполнить:

```bash
cd ~/tesl-reborn-android-review
git am /mnt/e/TESL-build/tesl-reborn-android-36-ota.patch && git push
```

Manifest и payload уже входят в патч. Повторно запускать publish_hook.py не нужно.
APK/Builder пересобирать и переносить игровые данные не требуется.

Полностью остановить игру через Android → сведения о приложении → «Остановить».
Запустить с интернетом, оставить открытой примерно на 20 секунд, затем снова
полностью остановить и запустить. Должен появиться текст о применении обновления 36.

Важно: пока скачивается сама OTA 36, работает старый код 35, в котором ещё нет
уведомлений. Поэтому первая загрузка этой функции может пройти без плашки;
сообщение о её применении появится после перезапуска. Дальнейшие обновления будут
показывать и скачивание, и предложение перезапуска.

Для проверки статуса с ПК в PowerShell:

```powershell
adb shell cat /sdcard/Android/data/com.bethsoft.theelderscrollslegends/files/tesl-reborn-update-status.json
```

Ожидается current.revision=36, current.version=android-36-update-notices, pending=null.
Затем повторный запуск не должен снова показывать «применено». Касания по области
плашки должны доходить до игры; загружаться и играть можно без ожидания проверки.

Локально проверяется работа с неизменённым загрузчиком API 1: скачивание, ошибочный
хеш, прерывание, применение при следующем запуске, отсутствие повторных сообщений,
работа до авторизации, поздний шрифт, смена разрешения, восстановление Canvas и
автоматическое скрытие. Настоящей Unity-игры и телефона для визуальной проверки нет.

Это изменение не исправляет ClientHttpErrorUnknown и не добавляет системное
автозаполнение паролей Android. Стабильный загрузчик, Java/Activity и авторизация
не менялись.
