# Android 34: тёмный переход при смене языка

Это изменение нативного APK. OTA остаётся на рабочей ревизии 32; публиковать
новую JS-ревизию и повторно передавать игровые данные не нужно.

## Установка

1. Применить патч в WSL и отправить коммит:

   ```bash
   cd ~/tesl-reborn-android-review
   git am /mnt/e/TESL-build/tesl-reborn-android-34.patch
   git push
   ```

2. В GitHub Actions дождаться нового успешного **Build Desktop Builders**
   именно на этом коммите. Скачать Windows Builder.
3. Выбрать прежние ПК-игру и оригинальный XAPK. Включить
   **Expert mode… → APK only (keep installed game data)**, собрать APK.
   Языки выбирать не требуется.
4. Установить APK поверх существующего приложения. Например, в PowerShell:

   ```powershell
   adb install --no-streaming -r "E:\TESL-build\output\tesl-reborn.apk"
   ```

   Заменить путь на фактический путь нового APK. Не удалять приложение,
   OBB или языковые пакеты. При установке поверх они сохраняются.

## Что изменилось

- Фон стартовых окон Game Data, сканера и возврата в Unity задан явно:
  тёмный `#171b22`, включая системную заставку Android 12+.
- Игровая Activity наследует исходную тему игры; её метаданные и ориентация
  сохраняются. Фон и светлые системные панели переопределяются отдельно.
- Убрана анимация перехода из Game Data в игру.
- Заголовок Game Data и build.json показывают Android 34; JS/core остаётся 32.

## Проверка на телефоне

Поменять язык EN → RU → EN из штатных Settings, открыть/закрыть Game Data,
перезапустить игру и открыть сканер QR. Проверить отсутствие белой вспышки
как при светлой, так и при тёмной системной теме. Язык загрузки, настроек
и коллекции должен совпадать.

Переход и перезапуск Unity пока остаются. Патч задаёт тёмный Android-фон;
он не меняет кадры, которые рисует сама Unity. Если белым окажется именно
игровой кадр, понадобится запись экрана для следующей диагностики.

Локальные проверки используют синтетические игровые данные: тесты, Java/DEX,
сборка APK+ZIP, XAPK и APK-only, подпись и декодирование скомпилированных тем.
Оригинальной игры и Pixel в среде проверки нет.
