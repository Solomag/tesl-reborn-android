# OTA 32 и тёмная тема APK/Builder 33

Патч содержит два коммита поверх Android 31. Применить один раз в WSL:

```bash
cd ~/tesl-reborn-android-review
git am /mnt/e/TESL-build/tesl-reborn-android-32-33.patch && git push
```

## Сначала проверить OTA без нового APK

В уже установленном APK 31 открыть Game Data → Advanced и оставить Automatic patch
updates включённым. Полностью остановить игру через настройки Android → Force stop.
Запустить, дождаться проверки обновлений (она начинается примерно через 10 секунд
после завершения инициализации hook). При сообщении о скачанном обновлении снова
полностью остановить и открыть игру. Загрузчик должен показывать
android-32-language-state-ota и current.revision=32; pending после старта — null.

ПК/ADB для загрузки не нужны. Ждать сборки EXE в Actions тоже не нужно: commit/push
уже публикует подготовленный манифест и JS. Адрес тестового канала:

https://raw.githubusercontent.com/Solomag/tesl-reborn-android/android-ui-and-update-loader/updates/test/manifest.json

В этой версии исходников updates/test/manifest.json уже revision 32. Если сайт
показывает 24, новое содержимое ещё не получено. Проверка выполняется один раз
за процесс; после сетевой ошибки повторяется при следующем полном запуске.

В OTA 32:

- Синхронизация SettingsManager, LocalizationManager и выбранного языка, включая
  уже инициализированный старым языком менеджер. Таблица и локализованные элементы
  обновляются вместе; ключи перевода Reborn сохраняются.
- Используется реальный LanguageSelectDropdown.HandleLanguageOnValueChanged.
  Нормальный Dropdown остаётся внутриигровым; выбор передаётся в проверенный путь
  применения ресурсов до вызова прежнего обработчика. Резервный Android-список
  остаётся, если не удалось распознать конкретный элемент.
- Game Data остаётся в SettingsWin_Mobile и убирается из OptionsWinMobile.
- Видимая тестовая область Ctrl+D выключается; рабочий жест остаётся.
  Если рамка осталась после первого старта нового JS, свернуть/развернуть игру,
  чтобы Android-процесс перечитал настройку. Последующее ручное включение отметки
  через Advanced сохраняется.

Проверить EN → RU → EN: загрузку, настоящие Settings и коллекцию, а также повторный
запрос пароля. Файлы отчётов подтвердили en_us / managerLanguage ru и установленные
словари; они не содержат enum-констант. Новый код определяет значения в рантайме
из метаданных игры. Тесты проверяют логику, но фактический результат на Pixel
ещё требует подтверждения.

Если язык останется разным, для диагностики теперь есть
files/tesl-reborn-language-state.json и расширенный Collect-Settings. Они не требуют
файлов пароля. Не удалять установленные языки для этой проверки.

## Тёмная тема

В Actions → Build Desktop Builders скачать Builder из последнего коммита:

- главное окно, поля, языковые списки, журнал и наши диалоги используют тёмную палитру;
- английский по умолчанию и исправленный Unicode-шрифт сохранены;
- системный диалог выбора файлов может следовать теме самой Windows.

Чтобы получить тёмный Game Data на телефоне, в новом Builder выбрать
Expert mode… → APK only (keep installed game data), затем Build APK only.
Языки выбирать не требуется. Установить APK поверх. OBB и уже установленные
пакеты на телефоне сохранить. Понадобятся прежние исходники ПК-игры и XAPK,
но выходной архив данных не создаётся.

Этот APK имеет заголовок Android 33, внутри него core ревизии 32. Это разные
версии разных частей приложения. Тёмный Game Data и экран сканирования QR —
Java/Android UI, поэтому старый APK 31 не получит их при скачивании JS.
Оформление самой игры и её графические ресурсы этим изменением не меняются.

## Дальнейшие обновления

Для JS-исправлений публиковать новый manifest + payload в updates/. Не нужно
каждый раз собирать APK/ZIP/OBB. Коммит одного hook.ts без обновления канала
не доставляет код телефону. Команда tools/publish_hook.py создаёт нужные два файла;
после неё нужны git add updates, commit и push. Номер ревизии должен увеличиваться.

Новый APK нужен для Java, камеры, Android-жестов, нативной темы или самого загрузчика.
Новые игровые ресурсы/языки устанавливаются отдельно через ZIP или передачу с ПК.
Скачивание и тихая установка новых APK этим OTA-загрузчиком не реализованы.

## Проверено локально

npm test, включая 23 Python-теста и новые проверки реального OTA-payload, рассинхрона
выбранного/внутреннего языка, штатного callback и корней UI из отчётов. Java
собирается в DEX. Полная синтетическая сборка с подписью проверяет обычный APK+ZIP,
XAPK и APK-only. Проверка не исполняет оригинальную Unity-игру. Настоящих Windows GUI
и Pixel здесь нет, поэтому отображение темы и игровой результат проверить локально
не удалось. Проблема обрывов браузерной загрузки APK в этот патч не входит.
