# OTA 57: видимый текст поиска колод

Требуется 56. Исправляется только поле поиска. Магазин, Settings, друзья, подпись и размеры поля не меняются.

Отчёт 12 подтверждает запуск 56 и установку поиска без исключений. По скриншоту фильтр действует, но текст/подсказка не отображаются. Точная причина отсечения текста на устройстве не доказана. В 57 убрана TMP-ветка с RectMask2D и использованы UnityEngine.UI.InputField + UnityEngine.UI.Text — как в DeckSearchField предоставленного ПК-плагина Reborn.

Обе текстовые компоненты используют встроенный Arial, явный цвет, MiddleLeft, без rich text и автоматического уменьшения. Поле однострочное. Выделенный текстовый прямоугольник, игровая рамка, иконка очистки, размеры и сам фильтр сохранены. Ограничение длины 100 символов.

Применить apply.sh, git push в android-ui-and-update-loader. Полностью закрыть и запустить игру для получения OTA 57. APK/OBB/языки не пересобирать.

Проверить подсказку до ввода, введённый текст во время ввода и после скрытия клавиатуры, длинный запрос, кириллицу и очистку. На реальном Android здесь не проверено.

Тест фактических конструкторов поиска проверяет совместимую пару Unity Text/InputField, явный шрифт/цвет/выравнивание, single-line и запрет rich text. Проверены фильтрация Unicode и остальные JS/Python-проверки, а также применение патча.
