The APK installs root `hook.js`, a stable loader containing the bundled fallback
core. `core.js` and `manifest.json` are generated by `npm run build` from root
`hook.ts`. Do not edit either JavaScript bundle directly.

`il2cpp-bridge.js` preserves the bridge bytes already present in upstream
`hook.js` at commit a2946d84257a88619809055139c6503f3b08554b, and in the tested
Android v21 release. It is **not** an upgrade to the latest npm bridge. The
snapshot publishes `globalThis.Il2Cpp`; our source is transpiled separately.
Its upstream project is https://github.com/vfsfitvnm/frida-il2cpp-bridge;
the MIT notice is included in `IL2CPP-BRIDGE-LICENSE`.

`channel.json` deliberately has no production feed. The release owner must set
a public HTTPS manifest URL before building the one-time loader APK. The
embedded default then works without an ADB configuration file. Existing device
configuration still overrides defaults.
